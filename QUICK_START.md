# 🚀 VELLUM Quick Start Guide

## Get Running in 3 Steps

### 1. Install Dependencies
```bash
cd vellum-app
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

### 3. Open Your Browser
The app will automatically open at **http://localhost:3000**

---

## First Time Flow

1. **Landing Page** → Click "Get Started"
2. **Login** → Enter any email/password (it's a demo - any credentials work!)
3. **Dashboard** → Start creating decisions!

---

## Quick Features Tour

### 🎨 Scribble Layer
- Click and drag to **draw**
- Click "T" icon to add **text**
- Click "○" icon to add **shapes**
- Use the trash icon to **clear all**

### 📋 Create a Decision
1. Click **"Create Decision"** (bottom center)
2. Fill in:
   - Title
   - Options (add as many as you want)
   - Constraints
   - Your reasoning
3. Click **"Analyze Decision"**

### 🤖 AI Analysis
- Click the **floating prism icon** (bottom right) anytime
- View structured AI analysis:
  - Reasoning architecture
  - Cognitive biases detected
  - Regret probability (short & long term)
  - Missed variables

### 📜 Archive Timeline
- Switch to **"Archive Timeline"** view
- See all your decisions
- Click **"Commit to Archive"** to make a decision immutable
- Watch the golden thread animation ✨

### 🌓 Theme Toggle
Click the **sun/moon icon** (top right) to switch between light and dark modes
