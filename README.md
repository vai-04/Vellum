# VELLUM — Decision Intelligence Archive
Final Product & Experience Documentation v1.1
1. Product Vision

VELLUM is a cinematic decision intelligence archive that captures human cognition across three layers:

Raw Thought (Scribble Layer)

Structured Reflection (Decision Layer)

Immutable Preservation (Archive Layer)

It is designed as:

A reflective cognition instrument

A luxury editorial thinking environment

A permanent intellectual memory system

Core statement:

The mind drifts.
Vellum captures.
Vellum preserves.

2. Cognition Layer Architecture

This is now the most important conceptual update.

Layer 1 — Scribble Layer (Unstructured Thought Capture)

Purpose:
Capture chaotic thinking, brainstorming, and emotional thought fragments.

Layer 2 — Decision Ritual Layer (Structured Reasoning)

Purpose:
Transform scribbles into structured, analyzable decisions.

Layer 3 — Immutable Archive Layer (Permanent Record)

Purpose:
Bind validated decisions to permanent memory with cryptographic proof.

3. Scribble Layer Feature Specification
3.1 Scribble Integration Model

Scribble is NOT a separate product page.

It is integrated into each decision memory.

Scribble Flow

Each logged decision expands into:

Decision Overview
↓
Structured Decision Content
↓
Scribble Section (Infinite Thought Canvas)

3.2 Scribble UI Experience
